# 输入/输出时域波形导出

## 使用

重新启动源码版 Quick_TDSNR，在「执行与波形 → 时域」中勾选样本，设置 Tx/Rx 和时域参数，点击「生成时域波形」，随后点击旁边的「导出波形…」。保存对话框可选：

- Excel 工作簿（`.xlsx`）：完整时间轴、输入激励及每个样本的输出；参数说明表记录信号与样本的对应关系。数值显示格式为 `0.000E+00`，即科学计数法小数点后三位；底层数值精度保持不变。无新增第三方依赖。
- 制表符分隔文本（`.txt`）：第一行为列名，后续每行一个完整采样点。仅保留以秒为单位的 `time_s` 时间列，没有 `time_ps`。所有数据使用大写 E 科学计数法，小数点后三位，例如 `1.250E-11`、`-2.010E-01`。TXT 实际写出四位有效数字，不生成配套 JSON 文件。

输入为现有算法使用的峰值 1 的归一化梯形源激励，**不是负载条件下另行计算的 Tx 端实际电压**。输出直接取自绘图数组，导出全部 FFT 点数；不截取当前视图，不改变算法，不另加幅度缩放。端口号为 1-based。

XLSX 数据列：`time_s`、`time_ps`、`input_norm`、`out0001_tx1_rx2` 等。数字以数值单元格保存，显示为科学计数法，超过工作表行列上限时分表。样本名称按文本保存，即使以 `=` 开头也不会成为公式。

TXT 列名：`time_s`、`input_norm`、`out0001_tx1_rx2` 等。输出序号与同一批次 XLSX 参数说明中的样本对应。若需要完整参数和更多数值精度，请同时导出 XLSX。

```text
time_s	input_norm	out0001_tx1_rx2
0.000E+00	0.000E+00	0.000E+00
1.250E-11	5.000E-01	1.234E-02
```

TXT 的三位小数是尾数小数位数（四位有效数字），时间也会舍入。在很长时间轴和很小采样间隔下，相邻时间点可能显示成相同数值；导出不会删除或合并任何采样行，需要区分更细时间时使用 XLSX 底层数据。

改变时域参数、端口或样本选择会停用导出，必须重新生成。计算期间改参数也不会把旧结果与新激励混合。导出在后台进行，暂时禁用生成/导出按钮；文件先写到目标目录的临时文件，成功后替换。

## 可选加载和回退

新增功能文件：

`src/quick_tdsnr/services/waveform_export_service.py`

**停用导出：关闭软件，删除该文件，或把它改名为 `waveform_export_service.py.disabled`，再启动软件。** 导出按钮消失，原有计算和绘图继续可用。保留备份后改名更便于重新启用。恢复原文件名并重启即可重新启用。

仅对原来的两个文件做了界面接入修改：

- `src/quick_tdsnr/ui/pages/sample_workspace_page.py`
- `src/quick_tdsnr/ui/main_window.py`

当前只支持 XLSX/TXT。源码回退使用本仓库 Git 历史；EXE 需重新构建。
