# 单物理通道 S2P 与 HSPICE 对比

这是一条单端、共地、互易、无串扰的理想通道，两个端口分别为发送端 1 和接收端 2。它不是差分通道，也不是实测 PCB 数据；差分通道通常需要四个单端端口。样例以解析模型生成，不需要电磁求解器。

## 文件

- `single_channel_50ohm_500ps_6dB.s2p`：直接导入工具的原始文件。
- `01_reference_circuit.sp`：电阻衰减器加理想传输线的独立 HSPICE 电路参考。
- `02_touchstone_channel.sp`：HSPICE 读取同一原始 S2P 的对比网表。
- `reference_waveform.csv`：4096 个采样点，含秒/皮秒时间、开路源电压、解析接收电压、工具接收电压、误差。可供波形软件导入或作为数值对照。
- `validation.json`：本机验证结果。
- `generate_and_verify.py`：可复现生成和验证脚本，使用现有算法，不改动应用代码。

## 通道定义与预期值

参考阻抗 Zref = 50 Ω；S11 = S22 = 0；S21 = S12 = 0.5 × exp(-j 2π f × 500 ps)。

因此 |S21| = 0.5，即 -6.020599913 dB，群延迟 500 ps；理想反射为零，绘图中的反射 dB 可能显示 -∞ 或显示下限。文件名中的 6dB 是简称，准确衰减为 6.0206 dB。

文件为 Touchstone 1.x，头部 `# Hz S RI R 50`，每行顺序为 f、S11、S21、S12、S22，每项 S 用实部和虚部表示。频率从 DC 到 500 GHz，步进 100 MHz，共 5001 点。高频范围是为 dt=1 ps 的解析测试专门生成，并不意味着真实线路能无色散地工作到 500 GHz。

电路实现：50 Ω 源电阻 → T 形匹配衰减器 → 50 Ω / 500 ps 理想传输线 → 50 Ω 负载。T 形衰减器两个串联电阻各 16.6666666667 Ω，中点对地电阻 66.6666666667 Ω。源电阻和负载不包含在原始 S2P 的内部电路中，需要在 HSPICE 外部接入。

工具计算的是接收电压与戴维南源开路电压之比。在本例两端匹配时，VTF21 = 0.5 × S21 = 0.25 × exp(-j 2π f × 500 ps)。

所以 1 V 开路源对应 0.5 V 的 Tx 端口电压、0.25 V 的 Rx 电压。频域选择 S21 时是 -6.0206 dB；选择 VTF21 时是 -12.0412 dB。不要把 S21 的 0.5 直接当作接收电压。

## UI、rise、dt、FFT 的关系

工具要求 UI、rise、dt 均为有限正数，FFT 点数为整数且至少 4，pre/post 为非负整数。要求 UI >= rise；建议 rise 至少包含约 10–20 个 dt。当前版本支持非整数 UI/dt 和 rise/dt，并按真实时间取样。N 推荐取 2 的幂；本例不使用界面默认的 dt=10 ps 和 N=256。

- 本例一个 UI 有 100 个采样间隔，上升沿有 20 个采样间隔。
- Nyquist 频率 fNyq = 1/(2dt) = 500 GHz，恰好覆盖文件最高频率，既不高频外推，也不丢弃文件高频范围。
- FFT 周期 T = N×dt = 4096 ps = 4.096 ns；实际时间数组为 0、1、…、4095 ps。
- FFT 频率间隔 ΔfFFT = 1/(Ndt) = 244.140625 MHz，单边 rFFT 有 N/2+1 = 2049 个频点。程序将输入 S2P 的 VTF 幅度 dB 和展开相位插值到这个频率网格。
- 原始 S2P 的 Δf = 100 MHz，与 ΔfFFT 不必相同。原始均匀频率网格对应 10 ns 的周期，足以描述本例 500 ps 延迟；插值增加点数不能补回真实测量缺失的信息。
- 时间窗必须容纳到达时间、完整脉冲/拖尾以及最后一个 post cursor 的搜索窗口。本例 main=560 ps，最后窗口的右边界为 560+20×100+10=2570 ps，小于 4095 ps。
- 改小 dt 时，先检查 fNyq 是否超过文件 fmax；例如此文件用 dt=0.5 ps，会要求 1 THz 并触发高频外推。增加 N 只扩大时间窗、减小 ΔfFFT，不改变 fNyq。
- 对一般真实文件，dt >= 1/(2fmax) 才不会要求高频外推；同时 dt 还应足够小以采清上升沿。二者不能兼顾时，需要更宽带的数据或更慢的激励。此处范围极宽是解析基准特性。
- 原始数据应覆盖足够低的频率，最好包含可信 DC；稀疏频率点、相位混叠、错误 DC 和非因果数据不能靠增大 N 修复。本文件具有精确 DC、等间隔频率与解析线性相位。

## 与 HSPICE 一致的激励

工具固定使用归一化 0→1→0 的单个梯形脉冲，没有 PRBS、重复时钟或额外源延迟。幅度基准为 1 V 开路源。UI 是用于构造该脉冲的标称半高宽，不是 HSPICE PULSE 的平顶 PW。

当前实现按真实时间计算梯形波。本例上升沿为 0–20 ps，下降沿为 100–120 ps，两者均为 20 ps；半高交点为 10 ps 和 110 ps，半高宽为 100 ps。即使 UI/dt 或 rise/dt 不是整数，也不会将边沿参数取整。

两份网表均使用以下 PWL，使每个 1 ps 采样点与工具相同：

```spice
Vdrive src 0 PWL(0 0 20p 1 100p 1 120p 0 4096p 0) AC 1
```

`PULSE(0 1 0 20p 20p 80p 10n)` 的首个脉冲与这里的连续梯形波一致。不要填 PW=100 ps，否则会把平顶加长 20 ps。对比时可使用提供的 PWL。

HSPICE `.tran 1p 4096p` 的报告步长与工具 dt 对应；求解器采用自适应内部步长，两者不是同一个概念。网表另以 `DELMAX=0.1p` 限制最大内部步长。S 元件的频域转时域处理和窗口可能因 HSPICE 版本而异，因此不能预先承诺 S 元件结果和工具逐位一致。

## HSPICE 运行和结果对照

在已配置好 HSPICE 可执行文件及许可证的终端进入本目录后运行：

```powershell
hspice -i 01_reference_circuit.sp -o 01_reference_circuit
hspice -i 02_touchstone_channel.sp -o 02_touchstone_channel
```

若用 HSPICE 图形界面，分别打开两个 `.sp`，工作目录设为本目录。第二个网表通过相对路径读取原始 S2P，不要直接替换成带自定义复数参考阻抗注释的重归一化输出。

先看第一份电路的 v(rx)，再看第二份 S 元件的 v(rx)，最后与 CSV 的 analytic_rx_V/tool_rx_V 比较。CSV 包含 0–4095 ps；HSPICE 结束于 4096 ps，多出的终点无需比较。绘图软件的秒时间轴需要乘 1e12 才是 ps。

| 检查量 | 理论结果 |
|---|---|
| v(src) 平顶 | 1 V |
| v(tx) 平顶 | 0.5 V |
| v(rx) 平顶 / 峰值 | 0.25 V |
| Rx 上升沿 | 500–520 ps |
| Rx 平顶 | 520–600 ps |
| Rx 下降沿 | 600–620 ps |
| 上升半高时间 | 510 ps |
| 源、接收各自半高点之间的延迟 | 500 ps |
| Rx 在 560 ps 的值 | 0.25 V |
| AC 下 vdb(rx)，源 AC=1 | -12.0412 dB |

网表的 rx_peak、rx_mid 和 flight 测量值分别应接近 0.25 V、0.25 V、500 ps。可先以幅度差 <1 mV、延迟差 <1 ps 作为排查目标；这是比较目标，不是已运行 HSPICE 得到的误差承诺。若有差异，依次核对开路源幅度、50 Ω 源/负载、PWL、时间原点、单位，再看 S 元件的插值/卷积设置。

当 AC 用 1 V 理想源、且接入 50 Ω 源电阻时，v(rx) 对应 VTF 而不是 S21。相位可按 360° 折返显示，对比时看展开相位或群延迟。

## 单通道 SNR 的解释与本机验证

没有 aggressor，所以 Xtalk Noise=0。Direct Noise 来自主游标之外各 pre/post 窗口内的绝对峰值之和，是工具的 ISI 指标；不是 SPICE 热噪声分析，也不是 BER 或眼图蒙特卡洛结果。

本例没有色散和反射，理论 Direct Noise=0、Signal=0.25 V、线性 SNR=∞。数值计算会留下约 1e-15 V 的误差，所以界面可能显示很大的有限 SNR；不要用这一巨大数值评估真实链路。工具采用幅度比 SNR=Signal/Total Noise，dB 值按 20log10(SNR) 计算。

已通过：电路 ABCD 独立解析校验、文件读回、互易性/无源性、工具预检、拓扑识别、实际重归一化服务和时域/SNR 服务。

本机结果：Signal=0.24999999999999983 V，main=560 ps，Direct Noise≈2.66e-15 V，Xtalk Noise=0，整段波形对解析参考的最大误差≈5.44e-15 V。详细记录见 validation.json。
