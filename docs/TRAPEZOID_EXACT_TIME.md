# 梯形激励按真实时间取样（2026-09-23）

默认激励不再将 UI/dt、rise/dt 取整。连续波形的四个拐点为：

`(0,0)、(rise,1)、(UI,1)、(UI+rise,0)`。

rise 为 0–100% 上升时间，下降时间与之相同；UI 为连续脉冲的半高宽，同时也是下降开始时刻。要求 UI >= rise > 0；UI=rise 为无平顶三角脉冲，UI<rise 明确报错。

计算依旧采用 `t[k]=k*dt`，保留 N 个采样点，并在每个时刻求上述连续波形的值。非整数边沿不会被推迟或提前到整数采样点。

示例：UI=108.7 ps、rise=25 ps、dt=12.5 ps、N=512：

| 时间/ps | 输入幅值 |
|---:|---:|
| 100 | 1 |
| 112.5 | 0.848 |
| 125 | 0.348 |
| 137.5 | 0 |

rise=30 ps 时，12.5 ps 处为 0.4166666667，25 ps 处为 0.8333333333；不会再强制在25 ps达到1。

## 采样与显示

均匀时间列中不会额外插入108.7 ps。采样点连线在折角附近仍只是近似；本次没有新增连续波形绘图层。上升沿只有少量采样点或脉冲短于dt时，仍需减小dt检查收敛；采样可能漏掉整个很短的脉冲，程序不会为了让它可见而把它拉长。

XLSX/TXT 导出共用同一激励函数。TXT仍使用三位小数科学计数法；XLSX保留底层精度。输出响应由新激励计算，频域插值、端接、IFFT和卷积算法没有改动。

## 兼容与缓存

- `trapezoidal_pulse` 的参数顺序和返回数组不变；关键字 `sample_rounding` 的默认值改为 `continuous`。
- 显式传入 `sample_rounding='nearest'` 或 `'floor'` 时，保留历史量化模式，仅用于兼容调用方。当前 Quick_TDSNR 计算和导出均不显式传入它，使用新的连续时间模式。
- 算法标记更新为 `parallel_sparam_snr_v2_continuous_pulse`。该标记进入波形缓存哈希和SNR结果记录，旧v1波形缓存不会命中。旧文件不主动删除。
- 关闭并重新启动软件，重新生成波形、重新运行SNR统计。已导出的旧报表、磁盘旧结果和当前窗口已有图像不会自动改写。
